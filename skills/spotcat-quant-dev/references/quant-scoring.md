# Quant Scoring Rubric

## 维度 (10 分制)

### 正确性 (3.0)
- 策略逻辑匹配验收标准
- 数据从真实、文档化的路径加载
- 未使用合成数据
- 无前瞻偏差

评分：
- 3.0: 所有标准满足，无问题
- 2.5: 所有标准满足，少量问题
- 2.0: 大部分标准满足，有些差距
- 1.5: 显著差距或轻微数据问题
- 1.0: 主要差距或检测到前瞻偏差
- 0.5: 几乎没有实现
- 0.0: 未实现或使用了合成数据

### 代码质量 (2.5)
Python 特有标准：
- 无 bare `except` 子句
- 公共函数有类型提示
- 无硬编码绝对路径（使用 pathlib 或 config）
- 遵循项目现有代码风格

评分：
- 2.5: 整洁，符合 Python 习惯，所有标准满足
- 2.0: 良好，少量问题
- 1.5: 可接受但缺少类型提示或有 bare except
- 1.0: 显著质量问题
- 0.5: 质量差
- 0.0: 无法接受

### 可维护性 (2.0)
- 策略参数在 config YAML 中，不硬编码
- 清晰分离：策略逻辑、数据加载、执行
- 配置变更不需要代码变更
- 遵循项目现有模块结构

评分：
- 2.0: 结构良好，config 驱动，易扩展
- 1.5: 足够结构化
- 1.0: 可以改进（如参数写在代码里）
- 0.5: 难以维护
- 0.0: 无法维护

### 测试覆盖 (1.5)
3 层测试：
- Unit tests (0.5): 逻辑正确性、边缘情况
- Backtest (0.7): 真实数据、性能指标、无前瞻偏差
- Data validation (0.3): 正确路径、完整日期、无合成数据

评分：
- 1.5: 全部 3 层完备
- 1.0: 2 层足够，1 层最小
- 0.5: 只有 1 层
- 0.0: 无测试或回测使用了合成数据

### 风险安全 (1.0)
- 策略默认 paper 模式
- 无显式启用不能自动交易

评分：
- 1.0: 所有安全规则满足
- 0.5: 轻微安全问题
- 0.0: 安全违反（同时触发总分 = 0 veto）

## 规则

- 每项扣分必须引用具体 file:line
- 评分客观、有据可查
- 通过门槛不可协商
- 安全规则违反覆盖所有分数（总分 = 0）
