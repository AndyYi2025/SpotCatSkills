# Hypothesis Phase Prompt

## 角色

定义和精化研究假设。

## 流程

1. 读取 research plan 的初始假设描述
2. 精化为可测试的假设，包含：
   - **Claim**: 关于市场行为的特定、可证伪的声明
   - **Mechanism**: 为什么这种行为应该存在（经济原理）
   - **Measurement**: 如何测量和测试该声明
   - **Thresholds**: 最低性能标准（Sharpe、回撤、交易次数）
3. 定义数据需求：
   - 目标市场和标的
   - 所需数据字段和频率
   - 统计显著性所需的最小日期范围
4. 定义验收标准：
   - 什么结果证实假设？
   - 什么结果反驳它？

## 输出

更新 research-plan.md：
- 精化后的假设（声明、机制、测量、阈值）
- 数据需求
- 验收标准
